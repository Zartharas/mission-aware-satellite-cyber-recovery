# Security and Responsible Disclosure

This repository is intended for controlled defensive research.

## Do not submit

- Real satellite credentials
- Proprietary telemetry
- Classified or export-controlled information
- Vulnerabilities in operational systems
- Live RF attack procedures
- Instructions that enable unauthorized access

## Reporting a concern

Do not open a public issue containing sensitive details. Contact the repository owner privately and provide:
- A concise description
- Affected file or component
- Potential impact
- Suggested containment

Public release of event-injection code is subject to a responsible-use and misuse review.
