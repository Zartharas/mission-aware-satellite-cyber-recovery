# Results

Raw and local experiment results are ignored by Git and must not be overwritten. The frozen WP9 raw campaign is distributed through Zenodo v1.0.0 rather than duplicated in GitHub.

Repository-tracked publication outputs belong under `publication/` (tables, figures, manuscript-facing claim controls) or another explicitly documented provenance location. Small reproduction inputs/reference contracts for the post-publication WP10 statistical reconstruction are tracked under `analysis/reference/`.

Do not force-add raw run directories under `results/`. A new experiment is a new replication and must use a separate provenance boundary.
