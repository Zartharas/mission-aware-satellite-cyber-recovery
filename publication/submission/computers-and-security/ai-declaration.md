# Generative-AI Disclosure Draft — Elsevier / Computers & Security

**Status:** prepared from Elsevier's current August 2026 journal policy; final wording requires author approval immediately before submission.

## Declaration of generative AI and AI-assisted technologies in the manuscript preparation process

During the preparation of this work, the author used **OpenAI ChatGPT** to assist with manuscript organization, editorial refinement, consistency checking, reproducibility documentation, and preparation of journal-submission materials. After using this service, the author reviewed and edited the content as needed and takes full responsibility for the content of the publication.

## Methods/reproducibility disclosure for AI-assisted code work

After the experimental campaign and historical statistical findings were frozen, **OpenAI ChatGPT** was used to assist with reconstructing, reviewing, and testing public reproducibility code from preserved derived inputs, statistical outputs, and provenance records. The original executable WP10 analysis source was not recovered. This AI-assisted post-publication reconstruction did **not** generate campaign observations, consume campaign seeds, modify the 720-VALID statistical population, alter the frozen WP9 evidence, or change the historical statistical outputs. The reconstructed implementation was independently regression-validated against preserved reference artifacts, deliberately tested for reference-tamper rejection, and validated in GitHub Actions. It is identified in the repository as a post-publication reproducibility reconstruction rather than the original analysis code.
