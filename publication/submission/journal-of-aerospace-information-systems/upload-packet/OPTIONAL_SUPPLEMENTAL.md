# JAIS Optional Supplemental Material Decision

## Current default

**Do not upload the Study-1 or Study-2 Zenodo archives, GitHub repository contents, raw evidence ZIPs, frozen analysis ZIPs, or internal audit files as ScholarOne supplemental material by default.**

AIAA's current supplemental-material guidance makes supplemental files optional and states that the primary article must be self-contained; acceptance is based on the article itself.

Paper 1 already provides public, durable research access through the manuscript's Data/Code Availability information:

- Study-1 Zenodo version DOI: `10.5281/zenodo.22181540`
- Study-1 Zenodo concept DOI: `10.5281/zenodo.22181539`
- Study-2 Zenodo version DOI: `10.5281/zenodo.22289114`
- Study-2 Zenodo concept DOI: `10.5281/zenodo.22289113`
- Public repository: `https://github.com/Zartharas/mission-aware-satellite-cyber-recovery`

## Why this default is safer

Duplicating the frozen evidence as ScholarOne supplemental material would create an additional publication-side copy whose identity would have to be independently checksum-locked and kept synchronized with the already published evidence-of-record. It provides little benefit when the article can cite durable public archives directly.

It also risks accidentally uploading internal provenance/audit material that was not intended as a journal supplement.

## When supplemental files may be appropriate

Prepare supplemental files only if one of the following occurs:

1. the live ScholarOne workflow explicitly requires a relevant file;
2. an editor requests a supplemental artifact;
3. a reviewer-facing table or dataset materially improves review and cannot reasonably fit in the self-contained manuscript; or
4. final editorial review concludes that a specific supplement is beneficial and the exact file can be independently frozen and audited.

If supplemental material is used, follow AIAA's current naming, self-containment, accessibility, cross-platform, copyright, and size requirements, and ensure the manuscript cites the supplemental item consistently.
