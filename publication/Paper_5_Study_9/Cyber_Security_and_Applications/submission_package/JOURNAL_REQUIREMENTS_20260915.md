# Cyber Security and Applications — Live Requirements Snapshot

Verified: 2026-09-15

Guide:
https://www.keaipublishing.com/en/journals/cyber-security-and-applications/guide-for-authors/

- Research Article is an accepted article type.
- LaTeX is recommended; editable source is required and PDF alone is not an acceptable source.
- Title page requires author/affiliation/corresponding-author details and the guide requests a full postal affiliation address.
- Abstract maximum: 350 words.
- Keywords: 3-6 in English.
- Highlights: encouraged; 3-5 bullets; <=85 characters each; separate editable file.
- Graphical abstract: encouraged, not mandatory.
- References in text and reference list must match; metadata should be correct and complete.
- Data statement: encouraged.
- Funding disclosure: required.
- Competing interests: required; complete Elsevier declarations tool and upload generated Word file.
- Generative-AI use in manuscript preparation: declare when applicable before references.
- Review model: single anonymized.
- Current APC shown in the live guide: USD 0 excluding taxes.
- Cover letter is useful but not listed as a mandatory file in the live guide.
