# Data and Code Availability

The protocol, semantic mapping records, deterministic analysis code, tests, accepted derived outputs, independent-audit outputs, and cryptographic artifact identities supporting this study are publicly available at:

https://github.com/Zartharas/mission-aware-satellite-cyber-recovery

The accepted Study 9 experiment is `S9-RTSI-001`, with canonical results under `study9/results/S9-RTSI-001_CANONICAL_RUN_20260914/`.

Third-party raw dataset bytes are not redistributed in the repository. The repository records source provenance and cryptographic identities for the analyzed public artifacts, while the original datasets remain available from their cited source publications and repositories.
