# Data Availability Statement

The data, code, analysis scripts, frozen protocols, result manifests, and audit records supporting this article are archived in the public GitHub repository:

https://github.com/Zartharas/mission-aware-satellite-cyber-recovery

The controlled Study 8 population and result authorities are maintained under `study8/` and `publication/study8/`. The separately governed Study 8E population, frozen SatNOGS observation-opportunity trace, corrected canonical results, and formal Results-002 freeze are maintained under `study8e/`.

Key frozen identifiers include:

- Study 8 experiment: `S8-PQC-ICR-001`
- Study 8E experiment: `S8E-ECTV-001`
- Study 8E corrected result freeze: `S8E-CANON-RESULTS-002-FREEZE-001`
- Study 8E frozen trace: `S8E-SATNOGS-TRACE-002`

The source trace contains public SatNOGS observation metadata used only as an observation-opportunity timing proxy. No private mission data, operational command logs, or human-subject data are included.

The public repository preserves the invalidated intermediate Study 8E result package as provenance but clearly marks it non-authoritative. Scientific claims in the manuscript use only the corrected formally frozen Results-002 authorities.
